From nothing to a widget on your phone, with live data, in a few minutes. You need Node 22 or later and the ShiftPane desktop app.

## Create a widget

```bash
npm create shiftpane-widget@latest
```

It asks for a folder, the widget's name, your GitHub login (the widget's `author`), and a template:

| Template | What it gives you |
| --- | --- |
| `pc` | A view bound to the PC's CPU. No collector, no code. |
| `web` | A collector that fetches from one host (GitHub, to start), and a view for its JSON. |

Pass them as flags to skip the questions. `npx create-shiftpane-widget my-widget --template web --author your-login` works in every shell; with `npm create`, the flags need a `--` before them, which Windows PowerShell drops.

## Run the collector

```bash
npx shiftpane-widget dev
```

It checks the folder, runs the collector on a sample PC, and prints what it returned. It runs again every time you save. Give config values with `--config key=value`; secrets a widget declares, such as `GITHUB_TOKEN`, come from environment variables of the same name.

## See it on your phone

<Steps>
<Step title="Turn on Developer mode">

In the desktop app, open **Settings** and turn on **Developer mode**.

</Step>
<Step title="Load the folder">

Open **Widgets → Installed** and press **Choose a folder**. The app shows what the widget can do, then installs it. Add it to your board from **Phone layout**.

</Step>
<Step title="Edit">

Change `view.json` or `collector.js` and save. The app loads the folder again and your phone redraws. A change that asks for a new permission isn't applied on its own: press **Load again** in the widget's settings, and the app asks you first.

</Step>
</Steps>

## Check and pack

```bash
npx shiftpane-widget validate   # every check the gallery runs that can run on your PC
npx shiftpane-widget pack       # <id>-<version>.zip, the file the gallery takes
```

The zip is deterministic: the same folder always packs to the same bytes and the same SHA-256.

## Share it

With Developer mode on, open the widget's settings in **Widgets → Installed** and use **Share to the marketplace**: it signs you in with GitHub, packs the folder and sends it for review. Or upload the zip on the [Publish](/upload) page. See [Publishing](/docs/publishing) for what happens next.
