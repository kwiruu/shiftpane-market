Widget Studio makes widgets without code, in the desktop app, with your phone showing the result as you go.

## Make one

1. **Pick a source:** CPU, GPU, memory, network, what's playing, and the rest of the [system sources](/docs/system-sources).
2. **Pick a component:** a ring, a value, a meter, history bars, a sparkline, a list.
3. **Bind them:** the GPU's percent to the ring, its history to the bars.
4. **Pick sizes:** small, medium, large. Each size is its own layout.

What you see on the phone is the widget. Save it, and it's a package like any other, ready to [publish](/docs/publishing).

## Describe it instead

Type what you want, such as "my CPU and GPU as two rings, with the network underneath", and the generator makes the widget and opens it in Widget Studio, where you can adjust it. It can write simple collectors too.

Generated widgets go through the same review as everything else, and are labelled as made with the generator.
