# Laptop Battery

The host laptop’s battery level, shown in five purple segments on a black card. Supports small and medium cards in ShiftPane 0.7.0 and later.

The lightning bolt appears while charging. The caption shows Charging, Fully charged, or the approximate remaining time supplied by Windows. Missing time estimates are omitted; a missing battery shows —% and Battery unavailable. No network access, collector, or configuration is required.

The meter fills proportionally to the actual percentage. Full segments are lavender; a partial segment is magenta. Colors stay purple at every charge level.
